Первая работа — Отчёт

Отчёт по первой работе

Отчёт о выполнении первой работы по созданию темы и пайплайна для фронтенда сайта.

Задание

Создать собственную тему на основе HTML, CSS, JS с использованием или без использования CSS-библиотек таких как Bootstrap, Bulma, фреймворков (например, Tailwind), JS-библиотек для разработки фронтэнда (например, React).

На основе репозитория разработать пайплайн или набор пайплайнов (yml-файл) для тестирования и сборки статики (HTML, CSS, JS) — фронтэнда сайта, а затем построения собственно самого сайта (интеграции контента в разметке Markdown в шаблон сайта) и деплоя его на GitHub Pages.

Необходимо учесть, что HTML файлы должны валидироваться на корректность, минифицироваться, должна быть предусмотрена сборка с помощью PostCSS. Дополнительным этапом (необязательным) реализуйте улучшение типографики содержимого сайта (например, используя инструмент typograf).

Минимальные требования к теме:

  • наличие кастомного header и footer
  • стилизованная страница для одной из секций (например, главной страницы)
  • метаданные сайта (название, описание, автор) (тег meta)
  • сайт должен быть доступен по адресу GitHub Pages, и все страницы и стили корректно отображаться
