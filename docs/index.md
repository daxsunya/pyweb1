# Первая работа — Отчёт

> **Превью:**  
> Это отчёт о выполнении первой работы по созданию темы и пайплайна для фронтенда сайта.  
> Содержит описание задания, выполненные этапы и структуру проекта.

---

## Задание

<details>
<summary>Показать задание</summary>

<p>Создать собственную тему на основе HTML, CSS, JS с использованием или без использования CSS-библиотек таких как Bootstrap, Bulma, фреймворков (например, Tailwind), JS-библиотек для разработки фронтэнда (например, React).</p>

<p>На основе репозитория разработать пайплайн или набор пайплайнов (yml-файл) для тестирования и сборки статики (HTML, CSS, JS) — фронтэнда сайта, а затем построения самого сайта (интеграции контента в разметке Markdown в шаблон сайта) и деплоя его на GitHub Pages.</p>

<p>Необходимо учесть:</p>
<ul>
<li>HTML файлы должны валидироваться на корректность.</li>
<li>Файлы должны минифицироваться.</li>
<li>Должна быть предусмотрена сборка с помощью PostCSS.</li>
</ul>

<p>Дополнительный этап (необязательный): реализовать улучшение типографики содержимого сайта (например, используя инструмент typograf).</p>

<p><strong>Минимальные требования к теме:</strong></p>
<ul>
<li>наличие кастомного header и footer</li>
<li>стилизованная страница для одной из секций (например, главной страницы)</li>
<li>метаданные сайта (название, описание, автор) через тег &lt;meta&gt;</li>
<li>сайт должен быть доступен по адресу GitHub Pages и все страницы и стили корректно отображаться</li>
</ul>

</details>

## Выполненные этапы

- Создан кастомный **header** и **footer**.
- Подключены **CSS и JS** для стилизации и интерактивных элементов.
- Реализован **видимый JS-элемент** (кнопка “Показать задание”), теперь заменена на expandable callout MkDocs.
- Настроена **структура проекта** для сборки с MkDocs.
- Подготовлен **workflow GitHub Actions** для автоматического деплоя на GitHub Pages.
